#   - Direct raw File IDs

#       * "1 to 3"  -> processes batch 1, batch 2, and batch 3

#       * "2-4"     -> processes batch 2, batch 3, and batch 4
#       * "1, 3"    -> processes batch 1 and batch 3
#       * "all"     -> processes all batches sequentially with cooldown
#   - batch_target: Specify a single batch number (e.g. 1, 2) or "all"
#   - batch_delay:  Cooldown delay in seconds between batches (default: 300 / 5 minutes)

#   python video_joiner.py -g example_links.txt --batch-index 1
